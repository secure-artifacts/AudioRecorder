# AudioRecorder

AudioRecorder 是一个基于 Tauri + React + CSS + 本地存储的桌面音频录制工具。

## 使用说明

1. 双击启动桌面窗口。
2. 首次运行会自动安装前端和 Tauri 依赖。
3. 点击绿色圆形按钮开始录音，再次点击停止录音。
4. 停止后可保存 `WEBM` 或 `MP3`，开启“自动保存”时会自动保存 MP3。
5. 默认保存到系统下载目录下的 `AudioRecorder` 文件夹。

## 功能说明

- 桌面窗口录音。
- 实时计时和频谱波形。
- 自动保存 MP3 开关。
- 自动缓存开关，录音中可按设定间隔覆盖保存 WEBM 缓存文件，并支持右键设置缓存清理策略。
- 手动保存 WEBM / MP3。
- 音频回放、进度条和音量控制。
- 文件命名规则：日期、时间、名称、编号、自定义、分隔符，可在设置面板中调整。
- 0-8 麦克风槽位选择，支持保存常用设备配置。
- 迷你模式和常规模式切换。
- 多预设管理，支持多个预设窗口独立打开、独立保存设置和记住窗口位置。
- 多窗口排列管理，支持托盘或预设菜单触发网格、横向、纵向、贴左侧、贴右侧和恢复上次位置。
- 时间码点击复制，支持右键选择复制样式。
- 全局窗口缩放档位，支持 100 / 90 / 80 / 70 / 60 / 50 六档一次性切换。
- 系统托盘图标，支持隐藏和恢复窗口。
- 云端链接/本地路径快捷打开。
- 本地存储保存常用设置。

## 安全审核发布流程

本仓库适用于 `secure-artifacts` 组织的软件审核流程。

1. 普通提交会触发 `.github/workflows/ci.yml`，执行前端构建和 Tauri 后端检查。
2. 推送 `v*` 标签会触发 `.github/workflows/release.yml`，在 GitHub Actions Windows runner 上构建 MSI。
3. Release workflow 会对 `dist/*` 中最终发布资产生成 Artifact Attestation，并使用 `softprops/action-gh-release` 由 `github-actions[bot]` 上传 Release。
4. 提交审核时选择“软件”，项目 URL 使用 `https://github.com/secure-artifacts/AudioRecorder`。

## 测试方法

1. 双击启动桌面窗口。
2. 点击开始录音，允许麦克风权限。
3. 录制 3-5 秒后停止，确认计时停止、音频可回放。
4. 点击“保存 MP3”和“保存 WEBM”，确认文件保存到下载目录。
5. 打开设置面板，修改日期、名称、编号、自定义字段，确认预览文件名同步变化。
6. 勾选或关闭“自动保存”，再次录音确认行为符合预期。
